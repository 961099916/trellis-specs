# Trellis Spec 模板库

收录适合中国开发者的 Trellis 编码规范模板，涵盖 Java / Spring Boot / 通用场景。

## 模板列表

### spring-boot-java
Spring Boot + MyBatis + MySQL 全栈规范，适合国内 Java 后端项目。

### java-se
Java SE 基础规范，适合纯 Java 库或工具类项目。

### generic
通用模板，适用于任何语言/框架项目，作为起点自行裁剪。

## 使用方法

```bash
# 安装模板
trellis init --registry https://github.com/961099916/trellis-specs
```
