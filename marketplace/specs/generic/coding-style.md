# 代码风格规范

## 格式规范

- 缩进：2 空格或 4 空格（项目统一即可）
- 行宽：不超过 120 字符
- 文件编码：UTF-8，无 BOM
- 换行符：Unix 风格（LF）

## 注释规范

1. **公开 API 必须有文档注释**（Javadoc / docstring）
2. **复杂逻辑必须加行内注释**说明意图，而非描述代码
3. **禁止注释掉的代码**直接留在代码库中，使用版本管理恢复

```java
// 正确：说明意图
// 等待异步任务完成，最多重试 3 次
retry(3, () -> task.await());

// 错误：描述代码（代码本身已说明）
// 调用 retry 方法，传入 3 和 lambda
```

## 格式化工具

使用项目配套的格式化工具（如 Prettier、ESLint、Spotless、Checkstyle），格式化命令：

```bash
# 自动格式化
npm run format

# 仅检查格式
npm run lint:format
```

## 规则

1. 代码提交前必须通过格式化工具
2. CI 流水线包含格式检查步骤
3. 禁止禁用单文件格式化规则（`.eslintrc` 注释绕过）
