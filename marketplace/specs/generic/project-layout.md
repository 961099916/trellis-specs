# 项目结构规范

描述本项目的目录结构和各目录的职责。

## 当前结构

```
src/              # 源代码
  ├── main/       # 主代码
  └── test/       # 测试代码

lib/              # 第三方依赖（Vendored 库）

docs/             # 项目文档

scripts/          # 构建/部署脚本

config/           # 配置文件（非敏感）
```

## 规则

1. **禁止在源代码目录存放配置文件**（`config/` 目录存放模板，实际配置通过环境变量或 `.env.local` 注入）
2. **敏感信息（密码、密钥、Token）禁止提交**，使用环境变量或 CI/CD Secret
3. **依赖外部库优先从包管理器引入**，避免 Vendored 重复代码
4. **每个功能模块有独立目录**，禁止将多个无关功能塞入同一文件

## 新增模块

新增功能模块时：

1. 在对应层级目录下创建子目录
2. 在 `index.md` 中注册该模块
3. 添加对应的测试文件
