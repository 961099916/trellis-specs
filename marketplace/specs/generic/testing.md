# 测试规范

## 测试要求

1. **新增代码必须附带测试**，核心逻辑不可无测试
2. **所有测试必须可通过 `npm test`（或对应命令）无报错执行**
3. **CI 流水线包含测试步骤**，测试不通过禁止合并

## 测试分层

| 层级 | 范围 | 速度 |
|------|------|------|
| 单元测试 | 纯函数、工具类、核心算法 | 毫秒级，可并行 |
| 集成测试 | 数据库、文件系统、外部 API 调用 | 秒级 |
| 端到端测试 | 完整用户流程 | 分钟级 |

## 规则

1. 单元测试必须隔离，不依赖外部系统（使用 Mock）
2. 集成测试使用独立测试环境，禁止污染生产数据
3. 测试描述必须清晰反映被测行为，使用自然语言
4. 测试数据使用 Builder 或 Factory 模式构造，禁止硬编码魔法值

## 覆盖率

- 核心模块覆盖率 ≥ 80%（行覆盖率）
- 新增代码覆盖率不可低于项目平均值
